## 👨‍💻 About Me

Full-stack software engineer based in **Morocco**, focused on building **robust backend services with Java & Spring Boot** and shipping them reliably with **Docker, CI/CD and Linux**.

I have delivered projects ranging from desktop applications to production web platforms, working across the whole lifecycle: API design, data modelling, frontend integration, containerization and deployment. I work in **Agile/Scrum** teams with Jira and care about clean architecture, testing and maintainable code.

- 🎯 **Focus:** Backend engineering (Java 17+, Spring Boot, REST APIs, microservices) and DevOps practices
- 🔭 **Currently deepening:** Kubernetes, cloud deployment and CI/CD pipeline automation
- 🤖 **Interests:** Applied AI and cloud-native architectures
- 💼 **Open to:** Java / Spring Boot Developer, Full-Stack and DevOps opportunities (on-site, hybrid or remote)
